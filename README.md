# Rijwijs (sample)

Persian-language PWA to prepare for the Dutch CBR car theory exam (rijbewijs B).
Sample build: one complete lesson, «Voorrang op kruispunten» (11 picture theory cards, 18 original questions in CBR formats, mini mock exam, mistakes review).

All questions and explanations are written from scratch, based on the law text (RVV 1990, BWBR0004825, version 2026-07-01).
Not affiliated with the CBR. The CBR website always prevails: https://www.cbr.nl
